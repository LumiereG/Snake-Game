# **Snake Game**
## **Overview**
> _This is a simple console-based Snake game built using C#. The player controls a snake that moves around the screen, eats apples to grow longer, and avoids collisions with itself and the boundaries. The game ends when the snake collides with its body or the walls._

### **Features**
- Snake Movement: The player can control the snake's movement using the W, A, S, D keys.
- Apple Generation: Apples are randomly placed on the board for the snake to eat.
- Growth: The snake grows every time it eats an apple.
- Collision Detection: The game detects when the snake collides with its own body or the walls.
- Score: The player's score increases as the snake eats more apples.
